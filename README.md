# Akademiets skolekantine

## Om prosjektet
Dette er en nettside for Akademiets skolekantine.
Her kan man se ukens meny, faste varer og kontaktinformasjon.

## Funksjoner
- Hjemmeside med informasjon om kantinen
- Menyside med mat for hver ukedag
- Vareside med bilder og priser
- Hover-effekter som viser mer informasjon
- Kontaktside med kontaktinformasjon

## Teknologi
- Python og Flask
- HTML
- CSS
- Jinja

## Kilder
- Bilder: Bildelenkene i data.py og style.css.
- Produktinformasjon: Produktinformasjon fra produsentene.
- ChatGPT: Brukt som hjelp til deler av Python-, HTML- og CSS-koden, hover-effekter, beskrivelser og tekst.

## Oppstart
1. Installer Flask med `pip install flask`.
2. Kjør `python app.py`.
3. Åpne `http://127.0.0.1:5000` i nettleseren.
